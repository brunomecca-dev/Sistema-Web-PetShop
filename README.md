# Sistema Web - PetShop Amigo Fiel 🐾

Bem-vindo ao repositório do projeto de desenvolvimento web do Petshop Amigo Fiel. Para facilitar a correção e garantir a integridade das entregas, o projeto foi dividido e estruturado em subpastas correspondentes a cada etapa avaliativa.

---

## Navegação e Teste das Fases

Escolha abaixo qual versão do sistema deseja visualizar e testar diretamente no navegador:

- **[Acessar a Fase 1 (HTML5 Semântico Puro)](https://brunomecca-dev.github.io/Sistema-Web-PetShop/Fase%201/index.html)**
  - _Foco:_ Estruturação modular limpa, uso de tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) e listagem inicial de produtos/serviços.

- **[Acessar a Fase 2 (Bootstrap, Carrossel e Formulários)](https://brunomecca-dev.github.io/Sistema-Web-PetShop/Fase%202/index.html)**
  - _Foco:_ Design responsivo com Bootstrap 5, carrossel de imagens dinâmico com acessibilidade (`alt`) e formulário estruturado de cadastro e agendamento.

---

## 📂 Estrutura do Repositório

- `Fase 1/` -> Arquivos originais da primeira entrega.
- `Fase 2/` -> Evolução do projeto com frameworks e interatividade.
- `MANUAL.md` -> Manual de instruções e documentação técnica.
